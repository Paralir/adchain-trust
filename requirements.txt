# AdChain Trust —— 运行依赖
#
# 版本策略：使用「下限 + 上限」而非完全锁死。
#   *锁死（如 ==1.2.3）会因为平台/架构差异导致评委 pip install 直接失败
#   * 完全不写版本（只有 >=）则可能拉到未来不兼容的大版本，破坏复现
#   * 因此这里给出可复现的版本区间，并在区间内向上兼容
#
# Python 版本要求：3.10+

# ---- Web 框架 ----
fastapi>=0.110.0,<1.0.0
uvicorn[standard]>=0.27.0,<1.0.0

# ---- 数据校验 ----
pydantic>=2.6.0,<3.0.0

# ---- 密码学（Ed25519 双签名）----
cryptography>=42.0.0,<46.0.0

# ---- 说明 ----
# 本项目刻意保持最小依赖，不引入数据库、消息队列、filelock：
#   * 并发写保护：使用标准库 threading.RLock（链级锁），
#     配合「临时文件 + os.replace + fsync」实现原子且不丢块的落盘，
#     单进程单文件场景下已足够，无需额外依赖。
#   * 持久化：使用标准库 json 落盘到 chain.json。
#   * 图像哈希：本期不实现（详见 main.py 中 AdInspector 的说明），
#     故不需要 Pillow / numpy / imagehash。
#
# 如需用 .env 文件管理密钥，可选安装：
#   python-dotenv>=1.0.0   （非必需，各平台均可直接用环境变量设置）
